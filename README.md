# Python Projects

A collection of Python projects built while learning and practicing Python programming through **freeCodeCamp**.

This repository contains practical exercises and small projects covering Python fundamentals, problem-solving, and progressively more advanced programming concepts.

## 📚 Projects

### 1. Employee Profile Generator

A beginner-friendly project that practices string manipulation, string concatenation, f-strings, type conversion, and string slicing.

**Concepts covered:**

* Variables
* String concatenation
* f-strings
* String conversion
* String slicing
* Indexing

[View Project](./Employee%20Profile%20Generator/)

---

### 2. Bill Splitter

A simple bill-splitting program that calculates a restaurant bill, adds a 25% tip, divides the total among friends, and rounds the final amount.

**Concepts covered:**

* Variables
* Numbers
* Arithmetic operations
* `+=` operator
* Division
* `round()`

[View Project](./Bill%20Splitter/)

---

### 3. Movie Ticket Booking Calculator

A movie ticket booking calculator that uses Boolean values and conditional statements to determine ticket eligibility and calculate discounts, extra charges, service charges, and the final ticket price.

**Concepts covered:**

* Boolean values
* `if`, `elif`, and `else`
* Comparison operators
* `and` and `or`
* Nested conditionals
* Arithmetic operations

[View Project](./Movie%20Ticket%20Booking%20Calculator/)
